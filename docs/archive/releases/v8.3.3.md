# v8.3.3

> 发布：2026-11-25。上游双模块升级吃改进红利：goagent-kernel v0.74 + goagent-runtime v0.6.4，零适配零行为破坏。

## 上游升级

- **goagent-kernel v0.73.0 → v0.74.0**
  - 本版为纯内部门禁/站点批（routeledger 路线达成对账、acceptancepath 验收路径证据、external_seam 外部依赖接缝判据、墙钟分类登记、站点三态配色），上游自述「无对外导出面变化」。
  - archcheck 新增 `CheckKindExternalSeam` 与 `RulerClassifications` 登记面均为 **policy opt-in**：argus `architecture-policy.yaml` 不声明即不激活，`make arch` 升级后实测 blocking=0 验证。
- **goagent-runtime v0.6.0 → v0.6.4**
  - 工具事件配对语义收紧：`EventToolCall` = 执行前请求事件（payload 带 args），新增 `EventToolResult` = 执行后收口事件（outcome/content/bytes，call_id 配对；审批拒绝专用 `approval_denied`）。
  - `chat.Delta` 增 ToolCall/Usage 可选字段（`chat.Model` 契约不变）+ 新 `chat/stream.go` `DeltaAggregator`——按 Index 归并工具调用、累计 usage 的唯一实现。
  - Joint 形态流式 delta 只即时广播不落事件行（观测面 ≠ 状态面）；挂载条件放宽为「Emitter 或 Joint 非 nil」。
  - `storage/sqlite.go → sqlitestore` 目录重构（接口不变）。

## 红利接线评估（结论：零代码适配）

- SSE 工具卡信号（`loopadapt.NewStreamEmitter`）按 typ 分发、忽略 payload——`EventToolCall` 提前到执行前 = **进度更早出现**，良性。
- `TraceTool`（pipeline Handler 装饰，与流式开关解耦）在收口事件红利下**仍成立不退役**：Emitter 缺省不挂时工具轨迹照走。
- `DeltaAggregator` 无 argus 消费面（不归并响应面）；Joint 形态未启用。
