# v8.8.3

> 控制台数据面系列（v8.7.0–v8.8.2）+ 依赖归属回迁 + 修复推送环内置验证器。

## 控制台数据面

- `GET /console/options`：下拉选项聚合（平台/角色/任务状态/严重度词表单源）
- `GET /members`：成员清单（凭证字段不出口；admin 管理面）
- `GET /repos/branches`：仓库分支速查
- `GET /repos/crs`：仓库在开 PR/MR 列表（控制台 PR 号下拉数据面）
- `GET /tasks` 增加筛选参数（平台/owner/repo/kind/verdict 等）
- `GET /auth/invites/history`：邀请历史（token 只存哈希，不投影凭证）
- `fix(api)`：reply 失败时透出服务层可读错误，不再只有泛化 500 文案

## 依赖与归属

  （kernel v0.80.0 / runtime v0.8.0；budget/spill/roundguard 引用不变）
- `oekit/pkg` 地板抬到 v0.61.5（#118）

## 修复推送环

- 新增 `argus fixcheck <worktree-dir>`（`ARGUS_FIX_VERIFY_CMD` 用）：
  对工作副本本轮改动文件做语法级校验（Go/JSON/YAML/Shell；有 python3/node
  时覆盖 .py/.js），不执行仓库代码、不落临时文件；**无可检查文件 fail-closed
  退出 1**，绝不把“无法验证”当成“验证通过”
- `deploy/k8s43/enable-fixpush.sh`：43 启用 `ARGUS_FIX_PUSH=confirm` 的可复现脚本
  （patch secret → rollout → 就绪检查；不写死任何 token）
