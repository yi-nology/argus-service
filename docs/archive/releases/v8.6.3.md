# v8.6.3

> 控制台正确性收口：任务详情元数据补齐、角色裁定边界可见、空预算/零覆盖展示修正。
> 纯增量（零 DDL、零破坏性 API 变更）。

## 修复

### 任务详情拿不到 PR 坐标（前端曾渲染 `undefined/undefined/undefined#undefined`）

- `GetTaskResponse` 增加 12–21 号字段：`platform` / `owner` / `repo` / `number` /
  `headSha` / `kind` / `fixStatus` / `tokensUsed` / `createdAt` / `updatedAt`
  （与 `ListTasks.TaskSummary` 同源同语义；时间为 Unix 秒）。
- `getTask` 从 `storage.Task` 回填；`createdAt/updatedAt` 零值不回填（避免 1970）。
- 前端 `normalizeTask` 已按 camelCase 归一，详情页标题/操作按钮恢复可用；
  坐标缺失时降级为「任务 <id>」并禁用审批/合并/意见跳转。
- `TestTaskVisibility` 增加元数据断言（含 createdAt 非零）。

### 平台管理员被 403 时的误导（角色边界是设计，不是故障）

- `admin`（平台管理）与 `maintainer`（业务裁定）物理分离：审批票/合并/推送
  只授予 maintainer（或静态部署超管 token）。此前页面只弹「查询失败」，
  看起来像 bug。
- 修复审批 / 合并资格门 / 受控推送三页新增权限说明 Alert 与 403 专用文案；
  无裁定权时隐藏/禁用写操作按钮，避免无效点击。

### 空预算与零覆盖展示

- 质量运营页：全局/按仓月度预算为 0 时显示「未设上限」，不再出现
  `每仓月度上限 0` 与 `0% / N / 0` 的失真进度条。
- 仓库设置页：「近 30 天生效情况」不再依赖设置覆盖是否存在——404（无覆盖）
  时也拉取 `stats/overview`，新仓库可看到真实任务量/节流/静默数据。
- 总览页「任务总量」改用 API 的 `tasks_done` 键（此前读不存在的
  `total_tasks`，永远显示 —）。
