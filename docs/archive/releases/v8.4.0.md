# v8.4.0

> 仓级回复控制（可选控制回复频次/数量/级别 + OCR 按仓开关）。

## 本版内容

- **#116 仓级回复控制四旋钮**（repo_settings 按仓覆盖，缺省继承全局）：
  - `comment_throttle_minutes` 同 MR 回帖最小间隔（窗口内跳过回帖，任务照常 done、报告落库、审计留痕）
  - `findings_cap` 单报告 findings 上限（severity 降序 top N）
  - `severity_floor` 级别地板（critical|high|medium|low，以下静默留计数）
  - `ocr_delegate_enabled` OCR 按仓开关（AND 部署 ARGUS_OCR_BIN，endpoint 红线不动）
- 配套前端「仓库设置」页（argus-frontend v8.4.0）：回复控制卡片 + 实时效果预览条
- 消费点：execute 链 assembleReport 后过滤 + Post 前节流门控 + OCR delegate 开关

## 升级注意

- 无 DDL（纯代码），verify 模式直接启动
- 新字段由前端/直接 API 写入；旧客户端不受影响（缺省=继承全局）
