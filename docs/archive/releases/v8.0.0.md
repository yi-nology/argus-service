# v8.0.0

> **多租户就绪度**——共享库 + `tenant_id` 贯穿维度全仓落地（#80 母票，30 子票关闭 28）。存量单租户部署行为零变化（未声明主体一律归 `default` 租户，一切键/路径/命名空间保持 legacy 无前缀形态）。

##  breaking

- **`/metrics` 默认开鉴权**（#106，`ARGUS_METRICS_AUTH` 默认翻转 true）：多租户下指标含各租户负载/用量信息不再默认匿名。**既有 Prometheus scrape 需配 Bearer 或显式置 `ARGUS_METRICS_AUTH=0` 回退**。

## 新配置

| 配置 | 说明 |
|---|---|
| `ARGUS_TENANT_PROFILES` | 每租户差量覆盖 JSON 文件（bot_username / llm / sink / octopus / audit_webhook / outbound_allow_extra / platforms / real_token_budget / webhook_base_url） |
| `ARGUS_API_TOKENS` `!tenant` 段 | token:scope**[!tenant]**[@repo][#expires]——token 认证租户归属 |
| `ARGUS_WEBHOOK_RATE_RPM` | webhook 每仓库坐标入站限速（缺省 60） |
| `ARGUS_CORS_ALLOW_ORIGINS` | 浏览器跨站 Origin 白名单（空=不校验） |

## 主要变化

### 地基（存储/身份/调度）
- 15 张业务表 `tenant_id` 列 + 全部唯一键/四表主键升维 tenant 首列；`tenant_scope_v1` 一次性迁移（回填/索引重建/SQLite 表重建/在飞防线 tenant 新定义即时重建）
- GORM 回调机制面：查询/更新/删除自动注入租户谓词 + 写入回填——「忘加过滤」的新端点泄露从纪律问题变机制不可能
- 调度面（认领/心跳/复位/重试/取消）显式跨租户——worker 池服务全部租户
- `tenant_repos` 映射表：webhook 入站坐标→租户归属；admin CRUD
- 审计行注入 `tenant` + `operator_fp` 字段（`s.audit` helper 单源）

### 凭证与出站（#90/#81/#82）
- 全体出站平台调用按 ctx 租户凭证路由（sdkctx `call` 三助手 `ProviderFor` 化）
- 每租户 workcopy 池：克隆目录与凭证指纹按租户分桶
- webhook 每租户目的地/签名密钥：ensure 按归属解析；入站签名候选集轮试

### 隔离面（#83/#84/#85/#86/#88/#91/#92/#94/#98/#99/#105）
- 副作用资源串/记忆命名空间/知识键（Milvus/本地文件/FP 回流）/share 令牌（HMAC 租户域+撤销清单+控制面 RevokeShare API）/缓存键/文件系统路径（spill/repomap/t-<tenant>）全租户分桶
- 知识检索装配单点过滤（knowledgefilter 装饰器）；SSE 事件带租户归属逐事件过滤
- 授权 pattern 下沉 SQL（`ListTasksScoped`）修 scoped token 截断页

### 租户配置消费（#93/#95/#96/#97/#101/#103/#104/#107）
- per-tenant LLM 模型栈（ModelBundle 视图，差量合成复用 BuildModels 全链）
- 租户级真实消费账预算（超限只熔断本租户）；出站守卫租户附加白名单
- sink/octopus/audit webhook 三旁路出口租户路由；BotUsername 租户感知
- 租户 GitHub App（每租户独立 installation TokenSource）；CORS Origin 白名单

## 迁移

1. 现有部署直接升级：所有存量行/键/路径自动归 `default` 租户，行为不变（唯一例外 = /metrics 鉴权默认翻转，见上）。
2. 多租户启用：登记 `tenant_repos` 映射 + 发 `ARGUS_API_TOKENS` 带 `!tenant` 的 token + 按需配 `ARGUS_TENANT_PROFILES`。
3. 迁移可由滚动升级自然完成（`tenant_scope_v1` 幂等哨兵，多副本租约串行）；或 `ARGUS_MIGRATE_MODE=job` 独立 Migration Job 先行。
