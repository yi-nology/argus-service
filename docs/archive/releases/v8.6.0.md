# v8.6.0

> Agent 执行面可观测 + 质量运营台：ReAct 运行/工具调用遥测、任务阶段时间线、
> 意见治理数据面深化、runtime 收编整理。

## 本版内容

### 1. ReAct 执行面可观测

- **运行遥测**：`plugin.HookAgentLoop` + 指标
  `argus_agentloop_{runs,attempts,rounds,tool_calls,uncertain}_total`
  （label=builtin|qa|r3）——回合消耗、回喂重试、未知态工具调用全域可见。
- **工具调用遥测**：`TraceTool` 扩为耗时/错误回调，三线统一上报
  `argus_tool_calls_total{label,tool,status}` +
  `argus_tool_duration_seconds`（histogram）。
- **告警规则**：未知态工具调用 >0（须对账、禁盲目重试）；attempts/runs >1.5
  （重试率过高）；工具错误率 >20%（15m）。
- **未知态守卫**：`RunReAct` 对 `res.Uncertain` fail-closed，不整程重试
  （runtime 纪律：结果未知先对账）。

### 2. 质量运营台（前端 /quality）

- 30 天 KPI（任务/裁决/token/误报抑制）+ 回复控制生效面。
- 本月 Token 三账本：配额口径（done）/ 逐调用实销 / 活跃预留；配额水位
  **按仓**计算（每仓月度上限语义）。
- 按仓巡检表：裁决分布、token、抑制、节流与 floor/cap 静默；直达
  「意见治理」与「仓库设置」（URL 预填）。
- 服务端质量台快捷入口 `/api/console`。

### 3. 意见治理深化

- `GET /findings` 增 `severity_counts`（严重度分布）与 `top_files`
  （噪声最高文件 top10，含出现/抑制计数）；前端治理台展示分布 Tags 与
  噪声文件排行（点击文件名筛选）。
- **租户隔离修复**：`FindingHistoryByFiles` 的 `Table+Scan` 绕过 GORM 回调，
  同坐标跨租户文件噪声会合并计数 → `Model+Find`；隔离测试补用例。

### 4. 任务阶段时间线

- 新增 `GET /tasks/:id/stages`（IDL 收编）：复用 `Service.TaskStages` 的零
  LLM 推导（stage_artifacts/进度标记/产物 → R1–R5 done），read 档 + 仓库维度
  判定；跨仓按不存在 404（不泄露存在性）。
- 前端任务详情展示「执行阶段」R1–R5 标签（best-effort 加载）。

### 5. runtime 收编整理

- `loopadapt.RunReAct` 单源 QA/builtin/R3 三处 ReAct 装配（去重 173 行），
  模型/工具表按 attempt 重建、失败/空终答回喂重试一次、OnReset/OnFinal/
  OnStats 参数化。
- 不用 `runtime.NewEmbedded` 模板的原因注释钉死（observe 异步事件会打乱
  流式增量与终稿快照顺序）；存储/工具管线仍用 runtime Mem/pipeline。
- `goagent-kernel v0.74.0 → v0.75.1`（runtime v0.6.4 文档地板，零破坏）。

## 升级注意
