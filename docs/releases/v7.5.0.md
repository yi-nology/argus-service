# v7.5.0

> 发布说明（sync-version.sh 脚手架 + 人工充实）。

## 本版内容

### #64 强释租约两段式协议 + push/PR 未知态自动对账

- `ForceReleaseResource` 扩展两段式协议（`confirm` + `reason`，service 层两道 400 闸）+
  `DryRunForceRelease` 只读预估（零写入）；同事务把 Unsafe + 在飞意图的 pending 行转
  **uncertain**（`forced release:` 留痕）——不经对账/人工 `force_retryable` 不重新开门；
- 新表 `side_effect_release_audits` 与释放同事务落持久化审计（schema.sql 同步）；
- `effect.RouterResolver` 按族分发：push=git ls-remote 探修复分支 / 近期提交扫任务标记；
  修复 PR=按源分支查既有 PR（不限状态，closed/merged 同样证明创建发生过）。

### #67 agent.delta 跨实例 fanout + reasoning 相位授权边界

- delta 与可靠事件同管道（Outbox→fanout，Event.ID 跨实例去重）；回滚开关
  `ARGUS_DELTA_FANOUT=0` 恢复 v7.4.x live-only；delta 行独立 1h 短保留期；
- reasoning 授权面 `AuthorizeDeltaPhase`（SSE 出口单点）：默认仅 admin 档，
  `ARGUS_DELTA_REASONING=admin|all|off`（未知值 fail-closed 回落 admin），拒绝计数进 authzDenied。

## 升级注意

- `side_effect_release_audits` 新表由 autoMigrate 自动建立；
- `ARGUS_DELTA_FANOUT` / `ARGUS_DELTA_REASONING` 两个新环境变量，缺省=多实例 fanout 开 + reasoning 仅 admin；
- 强释协议变更：管理 API 需带 `confirm` + `reason`（旧行为是单参数直释）。

push/PR 未知态自动对账（裸仓库实弹 + SDK 打桩双端到端）、双副本 delta 分发、
reasoning 三档授权矩阵、回滚开关）。
